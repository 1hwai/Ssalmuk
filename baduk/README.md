# 바둑 한 판

오목과 분리된 브라우저 바둑 프로토타입이다.

## AI 엔진

바둑 규칙 처리, 보드 상태, 입력 특성 구성, 정책 출력에서 착수를 고르는 로직은 engine.js에 자체 구현했다. 기존 외부 goban.js와 gui.js는 더 이상 불러오지 않는다.

AI는 KataGo g170 계열 Kyu/Dan 신경망 모델의 정책 출력을 사용한다. 신경망 실행에는 TensorFlow.js 4.22.0을 jsDelivr에서 불러온다. 초급·중급은 Kyu 모델, 고급·특급은 Dan 모델을 사용하고, 난이도별로 상위 후보 중 무작위 선택 폭을 조절한다.

- MCTS 탐색은 포함하지 않으며, 신경망 정책을 직접 사용한다.
- 모델 파일은 원본 프로젝트의 호스팅 주소에서 불러오므로 첫 AI 대국에는 인터넷 연결과 모델 다운로드가 필요하다.
- 모델 입력 특성은 이 프로젝트에서 새로 구현했으며, 기존 브라우저 프로젝트의 코드 파일을 복사해 사용하지 않는다.
- 모델 아키텍처 파일과 가중치의 출처·권리 상태는 별도로 확인해야 한다. 이 문서만으로 모델 배포 권한이 모두 해결되었다고 보지 않는다.

## 실행

저장소 루트에서 python3 -m http.server 8000을 실행한 뒤 http://localhost:8000/baduk/으로 접속한다. file://로 직접 열면 브라우저가 iframe의 출처를 격리하므로 AI 대전을 사용할 수 없다.

## 계가 규칙

대국 설정에서 한국식, 일본식, 중국식을 선택할 수 있다.

- 한국식: 간이 영역계가, 백 덤 6.5집. 포획한 돌과 확보한 집을 합산한다.
- 일본식: 간이 영역계가, 백 덤 6.5집. 포획한 돌과 확보한 집을 합산한다.
- 중국식: 간이 집+돌 계가, 백 덤 7.5집. 살아 있는 돌과 확보한 집을 합산한다.

한국식과 일본식은 이 프로토타입에서 같은 영역계가 계산을 사용한다. 규칙별로 사활·사석 및 빅(세키)을 자동 판정하지 않으며, 실제 공식 대국의 완전한 규칙 판정기가 아니라 간이 계가 기능이다. 두 차례 연속 패스하면 계가 결과를 표시한다.

## 라이선스와 상업 배포

LICENSE.md에 현재 조사 결과와 남은 확인 사항을 기록한다. 원본 goban.js와 gui.js 의존성은 제거했지만, 모델 가중치가 CC0라는 사실만으로 모델 JSON/그래프 정의와 실제 배포 파일의 권리 상태까지 자동으로 확정되는 것은 아니다. 상업 배포 전에는 실제로 사용할 모델 파일의 출처·체크섬·권리 상태를 확인하고, TensorFlow.js의 라이선스 고지를 배포물에 포함해야 한다.

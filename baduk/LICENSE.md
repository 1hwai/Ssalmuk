# 바둑 엔진 라이선스 및 출처 기록

## 현재 구현

`baduk/engine.js`는 돌담에서 직접 작성한 JavaScript 기반 휴리스틱 바둑 엔진이다. 외부 바둑 AI 모델, KataGo/GNU Go 코드, 외부 바둑 규칙 라이브러리를 실행 시 불러오지 않는다.

엔진은 기본 착수 합법성, 포획, 자충수 방지, 반복 국면 방지, 단순한 연결·활로·영향력 평가를 사용해 후보 수를 고른다. 이는 교육용·프로토타입 수준의 자체 AI이며, KataGo와 같은 전문 바둑 엔진이나 정밀한 형세 평가기가 아니다. 현재 계가는 별도의 간이 계산이고 사활·사석·빅(세키)을 자동 판정하지 않는다.

## 제3자 구성요소

| 구성요소 | 현재 사용 | 라이선스 / 조치 |
|---|---|---|
| 자체 바둑 엔진 | `baduk/engine.js` | 외부 모델 의존성 없이 자체 작성 |
| 바둑 UI·규칙 코드 | `baduk/game.js` | 자체 작성 |
| KataGo | 현재 사용하지 않음 | 향후 도입 시 엔진 코드와 선택한 모델 각각의 라이선스를 확인하고 별도 고지 |
| GNU Go | 현재 사용하지 않음 | 향후 도입 시 코드·실행 파일·라이선스 의무를 검토. 현재 정적 브라우저 앱에 연결되어 있지 않음 |

## 배포 관련 참고

현재 바둑 AI는 브라우저 안에서 실행되며, 외부 AI 모델 다운로드나 TensorFlow.js CDN이 필요하지 않다. 사이트의 다른 구성요소에는 별도의 제3자 라이선스가 적용될 수 있다.

이 문서는 기술적 출처 기록이며 법률 자문이 아니다.
